# Mini Racer 🏎️

A small, playable arcade racing game built with plain HTML, CSS, and JavaScript. No dependencies, build step, or downloads required.

## Play locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Controls

- **← / →** or **A / D** — steer
- **P** or **Esc** — pause / resume
- **Enter** — start or restart
- On phones, use the on-screen steering buttons or tap the left/right side of the game.

## Features

- Three-lane road with animated markings
- Traffic obstacles and collision detection
- Score, speed progression, and saved best score
- Start, pause, game-over, and restart screens
- Responsive layout and mobile touch controls
- Works offline after the page is loaded

## Deploy on Vercel

Import this repository in Vercel. It is a static site, so no build command is needed and the output directory can be left as the project root.

## GitHub Pages

You can also publish it with **Settings → Pages → Deploy from a branch → main → /(root)**.

Have fun, and watch the traffic!
